Privacy Policy

Last updated: November 23, 2026. This page describes CineLocal 2.8 (build 13).

CineLocal organizes and plays videos you already have. It does not have an account system, and it does not run a server that receives your movies. This page says what version 2.8 stores on the device and what it sends out, based on that version of the app.

Summary

  • Your videos stay on the device. Imported files are copied into the app's storage.
  • No ads and no tracking prompt. Version 2.8 does not include an advertising SDK, does not show an App Tracking Transparency prompt, and does not read the advertising identifier (IDFA).
  • Movie lookups go to Apple. On import, refresh, and poster search, a title and year guessed from the file name are sent to Apple's iTunes Search service. The poster is then downloaded from the image address Apple returns.
  • TMDB and OMDb are optional. They are used only if you save your own API key in Settings.
  • Sharing stays on your network. Watch Party, Nearby Stream, device-to-device copy, and SMB shares talk to devices or a server you choose. They are not uploaded to CineLocal.

What stays on the device

The app stores these on your iPhone or iPad:

  • Video files you import
  • Poster images it has downloaded or you have chosen
  • Library details such as title, year, overview, genres, and ratings
  • A TMDB API key and an OMDb API key, if you type them in Settings
  • SMB share addresses and usernames, plus the password for each share in the iOS Keychain
  • Display preferences and the purchase result the app reads from Apple

Deleting a movie removes that movie's file and poster from the app. Deleting the app removes the app's stored data from the device.

Movie details and posters

Before a lookup, the app strips the file extension and common tags (such as resolution and codec words) and pulls out a four-digit year when it finds one. It sends that cleaned title, with the year when it has one. It does not upload the video file. If the cleanup misses a word, that leftover word can be part of the title that is sent.

Each of these requests also carries the network address of the device (the IP address) and the standard description iOS attaches to a web request, which names the app and the system software. The app does not add an advertising identifier, an Apple ID, an email address, or the device name to these requests. The country and language values below are fixed in the app. They are not your location.

Apple iTunes Search

This lookup runs when you import a video, refresh a movie's details, or search for a different poster. It also runs when a TMDB lookup is not available. The app calls https://itunes.apple.com/search with the cleaned title, country=US, media=movie, entity=movie, and limit=10. No API key is sent. It then downloads the poster from the artwork address in Apple's answer, after asking for a larger image size than the small thumbnail.

Apple's own privacy policy is at apple.com/legal/privacy.

The Movie Database (TMDB)

Used only when a TMDB API key is saved in Settings. The key is sent with the request.

  • Search: https://api.themoviedb.org/3/search/movie with the key, the cleaned title (and year, when the app has one), include_adult=false, and language=en-US.
  • Details: https://api.themoviedb.org/3/movie/{id} with the key and language=en-US. The id is the TMDB movie id from an earlier match, not an id of your device.
  • Poster file: https://image.tmdb.org/t/p/w500 plus the poster path. This image request does not include the API key.

If a TMDB key is saved, import and refresh try TMDB first and use Apple if TMDB does not return a match. Choosing a different poster from the poster picker uses Apple's search, not a new TMDB search. TMDB's privacy policy is at themoviedb.org/privacy-policy. CineLocal is not endorsed or certified by TMDB.

OMDb

Used only when an OMDb API key is saved in Settings, and only after a movie match succeeds. The app calls https://www.omdbapi.com/ with the key, type=movie, and tomatoes=true. If the match includes an IMDb id, that id is sent. Otherwise the matched title and year are sent. The scores are saved on the device. OMDb is at omdbapi.com. Rotten Tomatoes and the Tomatometer are trademarks of Fandango. CineLocal is not affiliated with Rotten Tomatoes or OMDb.

Purchases

If you buy something in the app, payment is handled by Apple through StoreKit. The card number is entered in Apple's purchase sheet. The app does not read it and does not send it to a CineLocal server. The app asks Apple whether this Apple ID already has the unlock, and it keeps that result on the device.

Local network

Watch Party, Nearby Stream, and copying a movie to another device use Bonjour and Multipeer Connectivity on the local network, then a direct connection between the devices. Those connections are not sent through a CineLocal server. The app turns off cellular access for those device-to-device requests.

While a session is active, nearby devices can see:

  • The name of your device, as set in iOS
  • The movie title, shortened to 48 characters
  • A private Wi-Fi address (an address in the 10.x, 172.16–31.x, or 192.168.x range), a port, a 6-digit code, and a session token
  • For a copy or Nearby Stream, the file size

The video itself is sent only to the device that joins, or played from that device. Watch Party streaming in this version accepts MP4, M4V, and MOV.

Network shares use SMB only. There is no WebDAV client and no Plex client. The app sends the username and password you entered to the host you entered, so it can list and read files there. Those credentials are not sent to CineLocal. Playback from a share stays between the app and that host, with a local player on the device.

What this version does not include

  • An advertising SDK, including Google AdMob
  • An App Tracking Transparency prompt, or use of the advertising identifier (IDFA)
  • An analytics SDK or a crash-reporting SDK
  • A CineLocal account, or a CineLocal server that stores your library

The app and the transfer widget each include a privacy manifest. Both set tracking to off, list no collected data types, and declare on-device use of user defaults and file timestamps.

Buttons in the app can open the TMDB site, the OMDb key page, this privacy policy, Apple's standard terms, or this support site in the browser. That is a page you open yourself.

Children

CineLocal is not directed at children under 13. It does not ask for a name, email address, or phone number. A parent or guardian chooses what is imported.

Changes

If this page changes, the date at the top changes with it. Older text on this site described banner ads and an optional tracking prompt. That does not describe version 2.8.
