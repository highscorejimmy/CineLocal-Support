App Privacy

Last updated: November 23, 2026. This page describes CineLocal 2.8 (build 13).

This is a plain description of what that version of the app sends. It is not a set of instructions for App Store Connect. The same facts are written for readers in the Privacy Policy.

Privacy manifest in the app

The app and the transfer widget each ship a PrivacyInfo.xcprivacy file. In version 2.8 both files say:

  • Tracking is off, and the tracking-domain list is empty.
  • The collected-data list is empty.
  • The app reads user defaults and file timestamps on the device. The declared reasons are CA92.1 (information the app itself stored) and C617.1 (files inside the app).

Info.plist in this version does not contain NSUserTrackingUsageDescription, GADApplicationIdentifier, or SKAdNetworkItems.

Not in this version

  • Google AdMob, or any other advertising SDK
  • An App Tracking Transparency prompt
  • The advertising identifier (IDFA)
  • An analytics SDK or a crash-reporting SDK

Older copies of this page described banner ads and optional tracking. Those sentences do not describe version 2.8.

What does leave the device

There is no CineLocal server in this version. The internet calls the code makes are:

  • Apple iTunes Search (itunes.apple.com) for a cleaned title and year, then the poster image at the address Apple returns. This runs on import, on refresh, and when you search for a poster.
  • The Movie Database (api.themoviedb.org and poster files on image.tmdb.org), only if you save a TMDB API key. The key is included on the API calls. It is not included on the poster-image download.
  • OMDb (www.omdbapi.com), only if you save an OMDb API key. The request carries that key and either an IMDb id or the matched title and year.
  • Apple's App Store, through StoreKit, if you make a purchase or the app checks whether this Apple ID already has the unlock. The app does not read the card number.

Watch Party, Nearby Stream, device-to-device copy, and SMB shares stay on the local network or on the SMB host you type in. They are not sent to a CineLocal server.
